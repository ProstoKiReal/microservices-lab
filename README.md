# microservices-lab

Лабараторная по микросервисам

## Задача 

Неообходимо написать 2 микросервиса: заказы уведомления.

## Что нужно реализовать

- Event Driven архитектура через Kafka
- In/OutBox pattern
- Настроить трейсинг
- Настроить логирование + поиск по логам
- Настроить мониторинг
  

## Технологии

- **FastApi**
- **FastStream**
- **FastStream Outbox**
- **Dishka**
- **Postgresql**
- **Kafka**
- **SqlAlchemy**
- **Alembic**
- **Docker**
- **Prometheus**
- **Grafana**
- **Loki**
